# Zexora Gaming

A fully responsive gaming portfolio website built with **React.js** and **CSS Modules**.  
This project demonstrates a modern UI design with interactive elements, including:

- Responsive Navbar with scroll effect
- Swiper.js Testimonials slider
- Works section with hover and marquee animations
- Contact form with interactive inputs and buttons
- Social media icons with hover effects

## Features

- **Responsive Design:** Works seamlessly on desktop, tablet, and mobile
- **React Components:** Organized and reusable components
- **Interactive Animations:** Smooth hover effects and transitions
- **Mobile Menu:** Hamburger menu for screens < 1200px

## Technologies Used

- React.js
- CSS Modules
- Swiper.js
- React Icons
